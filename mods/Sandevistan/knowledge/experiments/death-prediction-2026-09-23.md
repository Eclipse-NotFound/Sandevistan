# v1.142 时停死亡预判偏严：研究与修复

用户明确的症状是“已经打出足够致死的攻击，敌人仍不出现预判死亡”。本轮核对本体实际碰撞、命中随机、damage 减伤顺序，以及 Sandevistan 的清零、记账、预告与恢复链路。主要对象是根目录 1.02 宿主的玩家子弹和近战；没有改真实击杀或玩家受伤规则。

## 根因与对照证据

下表为 World.testDam=true、无暴击等随机干扰的独立用例。输入 100 指攻击体已有的伤害（已经包含发射时武器耐久和弹药倍率），不是武器面板值。

| 条件 | 旧预判 | 本体实际 / 新预判 |
|---|---:|---:|
| 无甲，输入 100 | 90 | 100 |
| 低耐久武器，攻击体已含耐久减伤 | 76.5 | 100 |
| 激光；物理甲 70、能量甲 10 | 27 | 90 |
| 物理甲 70、耐久 50，本击破甲 | 27 | 100 |
| 物理甲 20，必定 2 倍暴击 | 162 | 160 |
| 对小马倍率 1.5，物理甲 20 | 108 | 130 |
| 95 HP，输入 100 | 不预告 | 预告，真实 HP 仍为 95 |
| 两次各 40 的挥击，同一攻击体 | 36 | 80，重复扫描同一次不重算 |
| 真实接触且同一步出链的子弹 | 没有记录 | 100 |

1. 旧 slowStepWorld 在 loc.step 后只扫描存活链表；本步离场的子弹没有机会记账。现在步前保留本步攻击体引用，步后读取其 parr，出链不丢碰撞。
2. WClub 构造一次隐藏 Bullet，每次挥击替换 parr。旧 hitCred 按 Bullet 一生去重，第二次挥击被排除；清零后还只在 damage>0 时读取接触，较晚发生的刃部扫掠也会漏掉。现在缓存原始伤害、持续读取接触，以 parr 数组身份区别挥击代次，以目标去重同次接触。
3. 旧公式统一乘 0.9、重复扣武器耐久、全部使用物理甲，并把类别特攻放在护甲之后、暴击放在护甲之前。这些不是游戏的真实结算顺序。
4. 旧公式不累计预计破甲/破盾，也把随机覆盖的护甲当作每次固定折算值，导致本可破防的攻击被压成零。
5. 修正同时保留反向边界：完整闪避、无敌、无接触均不计致死；删除位置盒猜测。WKick.actions 内联 bindMove 会已扣真实 HP，不把这份伤害再加入延后账本；原生踢击实测扣 40、延后记录为空。

## 新算法

新增独立模型 src/SandyDamagePredictor.as，主流程负责收集接触与预告，模型负责命中率和伤害期望。

- parr 在随机命中判定之前写入，表示接触尝试而非必定命中。按 udarBullet 的短路条件计算命中率：dexter<=0 或普通弹 precision<=0 直接通过对应层；其他弹按 accuracy 对 dexter；近战按 dodge；miss 单独处理。
- 用攻击体原始 damage，先乘类型易伤、玩家对目标类别倍率及电击离地等环境倍率。武器耐久已在 shoot/resultDamage 中处理，不再二次折扣。
- 普通随机伤害 [0.7,1.3) 用固定 9 点中点积分，不消耗游戏随机数。World.testDam 下只算固定输入，便于与本体严格对照。
- 每个样本先扣独立记录中的护甲耐久；本击破甲立即取消其覆盖。物理组用 armor，能量组用 marmor，其他伤害依原生规则跳过这两组；护盾在破掉的本击仍减伤。
- 随机护甲覆盖分别算有甲/无甲结果再平均，不能先平均护甲值再钳伤害为零。之后按原生顺序计算普通暴击、偷袭、分解和全局易伤的类型例外。
- 每个目标维护预计护甲/护盾状态，连续攻击能够逐步破防；未命中的概率不消耗这份预计耐久。所有状态与真实实体隔离，restorePredDead 清空。
- 累计预计伤害达到当前真实 HP 才播放既有死亡预告，回放前恢复；真实 HP、护甲、弹药和死亡掉落由原游戏结算。

脚本 build/tests/run-death-prediction.ps1 在独立 app id 下启动当前游戏资源的副本，只加载 Sandevistan。测试代码注入 build/out 临时源码，正式 SWF 不含专项驱动。每次退出只处理自己启动的 PID，不接触真实 pfe 存档。

- 同一有效夹具的旧版对照：52 项中 47 项失败；完整输出 baseline-v1.141.txt。旧源码从提交 ed1391b 对应的主源码保存到 build/out/death-prediction/baseline-v1.141.as，用 -Source 指定并加 -ExpectFailure。
- 最终专项：53/53 通过（新增真实 WKick 防双记用例）；candidate-v1.142.txt。涵盖伤害类型、耐久、累计破甲/破盾、命中短路、随机覆盖、偷袭/分解、炮塔方向、延迟近战和同帧出链。
- 随机覆盖：2400 次原生结算均值 50.5833，模型 50；伤害波动越甲阈值：原生均值 1.8020、解析值 1.875、9 点模型 1.85185。随机均值只按统计容差检查，不声称逐次 RNG 相同。
- 动画回归：掠夺者/尸鬼 × 五档速度及 AI 模式，574/574 帧逐像素一致，12 项尸体保护通过；animation-regression.txt。
- 正式构建 build/out/SandevistanMod.swf 直接以 -Smoke -Artifact 启动，20 PASS / 0 FAIL / 1 SKIP；artifact-smoke.txt。跳过项是隔离实例未安装 ModSettings 的注册。死亡攻击检查 snapSize=0 不能视为新增攻击冻结覆盖。
- 首轮夹具失败不作为修复证据：新档没有当前武器、虚构 pistol1 ID 无效；改用 AllData 中实际武器。Unit.setNull 不是从场景移除，旧目标会抢先碰撞；改为 units 删除 + remObj + remVisual。最早使用 liv=30 时弹体仍存活；有效出链用例用 liv=1，并断言 in_chain=false、parr[0]===当前目标。发布基线使用修正后的夹具重新验证。

日志文件均在同级 death-prediction-20260923/。可重新运行：默认专项；run-replay-animation.ps1 跑动画；run-death-prediction.ps1 -Smoke -Artifact <SWF> 跑发布字节流程。

## 验证边界

- 这是伤害期望，不保证每次回放随机结果必定致死。随机耐久用均值状态延续，未枚举所有历史随机分支；9 点积分在破甲阈值等不连续处也有近似误差。
- 预判仍以时停中实际发生的接触为依据，未碰到敌人的在途子弹不会凭方向提前算命中。
- 本轮没有重建爆炸半径、气体持续伤害、附加燃烧/毒伤、念力撞墙等缺失的预判入口；没有完整覆盖穿透后续伤害衰减及所有 Boss/特殊实体的 damage/udarBullet 覆盖。炮塔临时护盾做了明确支持。这些不能宣称已完全解决。
- 针对当前 1.02 真实类验证；未做 1.03/1.04 或联机/全部模组混战验收。
- 原先 MEMORY 的“预判死亡偏松”是历史问题概括；本次用户症状及证据是系统性漏记/低估，同时仍保留上述概率与特殊路径的不确定性。
