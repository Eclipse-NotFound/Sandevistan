【模组功能】
  · 游戏中按快捷键（默认 \ 反斜杠）触发"斯安维斯坦"技能
  · 生效期间（默认 8 秒）：
      - 时间停止：敌人、子弹、念力投掷物、移动物体全部冻结
      - 玩家照常移动、攻击（近战伤害即时生效）
      - 玩家发射的子弹、投掷物在空中定格
      - 彩色残影特效（类似《赛博朋克:边缘行者》），紧贴角色本体
      - 粒子特效（枪口火焰/火花/血花）继续飞舞
  · 生效结束后：
      - 时间恢复正常，定格的子弹继续飞行
      - 快速回放（5 倍速）你在生效期间的操作（彩虹残影）
      - 进入冷却（默认 40 秒），HUD 显示剩余时间
  · SATS 暂停状态下按快捷键也能触发（自动关闭 SATS）

【参数面板】（v1.1 新增）

  · 面板操作：↑/↓ 选择参数，←/→ 调节数值，Enter 保存并关闭，Esc 关闭
  · 可调参数：生效时长 / 冷却 / 回放速度 / 残影密度 / 特效开关 / 热键
  · 保存后实时生效并写回 config.txt

【安装方法】
  1. 把整个 SandevistanMod 文件夹放到游戏根目录
     （与 pfe.swf、Remains.exe 同级）
  2. 双击运行 安装.bat（自动备份原版到 backup\ 并安装补丁）
  3. 从 Steam 正常启动游戏
  4. 进入游戏后按 \ 键触发
  注：左上角会显示"SandevistanMod v1.42 已加载"标记
     （可在 config.txt 中设置 showmark=0 隐藏）

【修改设置】
  方式一：游戏内按 F9 打开参数面板（推荐）
  方式二：用记事本打开 config.txt：
    hotkey      = 220    触发热键（220=\ 33=PageUp 34=PageDown 36=Home 112-123=F1-F12）
    duration    = 240    生效时长（帧，30帧=1秒，240=8秒）
    cooldown    = 1200   冷却（帧，40秒；0=无冷却）
    replayspeed = 5      回放速度倍率
    ghostevery  = 3      残影密度（帧间隔）
    fxrun       = 1      时停期间特效是否继续（1=继续 0=冻结）
    showmark    = 1      是否显示"已加载"标记
    panelkey    = 120    参数面板热键（120=F9）
  保存后重启游戏生效。

【卸载方法】
  双击运行 卸载.bat（从 backup\ 还原原版文件）

【解决输入法卡键的系统设置（推荐）】
  方法一（最推荐）：彻底禁用中文输入法，只保留英语键盘
    Windows 设置 → 时间和语言 → 语言 → 中文 → 选项 → 键盘 →
    移除"微软拼音"（保留美式键盘）
  方法二：关闭 Shift 切换（保留 Ctrl+Space）
    Windows 设置 → 时间和语言 → 输入 → 高级键盘设置 →
    输入语言热键 → 更改按键顺序 → 切换输入语言改为 Ctrl+Shift
    或"未分配"；切换键盘布局改为 Ctrl+Shift
  方法三：游戏中改绑跑步键（Shift → 其他键）
    游戏设置（PipBuck → 选项）里把 keyRun 改绑到 Ctrl 等
  方法四（临时）：卡键时按 Ctrl+Space 切回英文即可恢复

        无论游戏是否因残留忽略本次按键，按键都立即生效；
        UI 占用输入时（键位重绑/菜单/商店）自动跳过
      - 实测验证：伪造按键事件后 keyRight 立即生效 ✓
  · 注意：若你在游戏设置里自定义过键位，自定义的键不受自愈保护
